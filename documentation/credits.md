## Icons & Illustrations

All icons and product illustrations are original, hand-authored inline SVG created for this template — no external icon library or stock illustration set is used. They are inlined per page (as `<symbol>` sprites) so the template works fully offline via `file://` and every icon adapts to light/dark mode through `currentColor`.

## Imagery

No stock photography is used. Product visuals are represented with the original SVG icon set described above, per the template's "original illustrations over stock photography" design direction.

## Libraries

None. The template is built with plain HTML5, CSS3 and vanilla JavaScript (ES6+) — no frameworks, UI kits or JavaScript libraries are included.

## Content
